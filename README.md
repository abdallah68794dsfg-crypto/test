# عيد ميلاد نور الدين ✦

موقع تهنئة عربي بتصميم أسود وذهبي، تم تجهيزه ليوم 22 نوفمبر 2026.

## الملفات
- `index.html` — هيكل الصفحة والأقسام.
- `style.css` — الهوية البصرية والتصميم المتجاوب.
- `script.js` — العد التنازلي، معرض الصور، الرسالة، المشاركة والاحتفال.
- `images/photo-1.jpg` إلى `images/photo-6.jpg` — صور الذكريات.
- `birthday.mp3` — ملف الموسيقى الاختياري.

## تشغيل الموسيقى
زر الموسيقى يعمل بعد الضغط عليه. يجب رفع ملف باسم `birthday.mp3` في جذر المستودع بجوار `index.html`. المتصفحات قد تمنع التشغيل التلقائي.

## نشر الموقع
المشروع مجهز لـ GitHub Pages. من إعدادات المستودع افتح **Settings → Pages** وتأكد من تفعيل النشر عبر GitHub Actions. بعد نجاح آخر عملية نشر افتح:
