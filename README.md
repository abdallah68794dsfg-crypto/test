# عيد ميلاد نور الدين 🎂

موقع عربي RTL بتصميم أسود وذهبي لعيد ميلاد نور الدين بتاريخ 22 نوفمبر 2026.

## ملفات المشروع
- `index.html` — الصفحة الرئيسية.
- `style.css` — التنسيق والتصميم.
- `script.js` — التفاعلات والعد التنازلي.
- `images/` — مكان صور المعرض.
- `birthday.mp3` — ملف الموسيقى (يُضاف إلى جذر المشروع).

## إضافة الصور والصوت
ارفع الصور الست بالأسماء التالية داخل مجلد `images`:
`photo-1.jpg` إلى `photo-6.jpg`.

ارفع ملف الصوت باسم `birthday.mp3` بجوار `index.html`.
تأكد من أن أسماء الملفات وحروفها مطابقة تمامًا.

## النشر
المستودع مجهز بسير عمل GitHub Actions في `.github/workflows/static.yml`.
من إعدادات المستودع افتح **Settings → Pages** واجعل المصدر **GitHub Actions** إذا لم يكن محددًا بالفعل.
بعد نجاح سير العمل سيظهر رابط الموقع في **Settings → Pages**.

## تشغيل محلي
افتح `index.html` في متصفح حديث. لتجربة الصوت، اضغط زر تشغيل الموسيقى داخل الموقع.
