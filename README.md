# عيد ميلاد نور الدين 🎂

موقع تهنئة عربي باتجاه RTL وتصميم أسود وذهبي، مخصص ليوم 22 نوفمبر 2026.

## محتويات المشروع
- `index.html`: الصفحة الرئيسية والأقسام.
- `style.css`: تصميم متجاوب للموبايل والكمبيوتر.
- `script.js`: العد التنازلي، تشغيل الموسيقى، الهدية، معرض الصور، المشاركة والاحتفال.
- `images/photo-1.jpg` إلى `images/photo-6.jpg`: صور المعرض.
- `birthday.mp3`: الموسيقى.

## تشغيل الموسيقى
الموقع يحاول تشغيل الموسيقى تلقائيًا عند الفتح. بعض المتصفحات تمنع التشغيل التلقائي للصوت؛ في هذه الحالة يبدأ التشغيل بعد أول تفاعل مع الصفحة أو عند الضغط على زر الموسيقى.

## الصور
الصور مضمنة بالفعل في مجلد `images`، وتفتح بالحجم الكبير عند الضغط عليها.

## النشر على GitHub Pages
1. افتح **Settings → Pages**.
2. اختر **GitHub Actions** كمصدر للنشر.
3. انتظر نجاح سير العمل، ثم افتح رابط الموقع الظاهر في صفحة Pages.

## ملاحظة
يفضل فتح الموقع من رابط GitHub Pages وليس من معاينة ملفات GitHub. إذا لم تظهر آخر التعديلات فورًا، حدّث الصفحة أو افتحها في نافذة خاصة لتجاوز النسخة المخزنة مؤقتًا.
